# سایت نمایندگی خودرو — راهنمای نصب

## پیش‌نیازها
- PHP 8.1 یا بالاتر (تست‌شده روی 8.3) با افزونه‌های `pdo_mysql` یا `pdo_sqlite`، `gd`، `curl`، `mbstring`، `openssl`، `fileinfo`
- MySQL / MariaDB (پیشنهادی برای سایت واقعی) یا SQLite (برای تست سریع)
- هاست اشتراکی cPanel/DirectAdmin یا سرور مجازی؛ بدون نیاز به Composer یا Node

## ساختار این مخزن
محتوای این مخزن دقیقاً همان چیزی است که داخل پوشه public_html هاست قرار می‌گیرد:
پوشه‌های app، public و storage و فایل‌های .htaccess و config.sample.php.
فایل .htaccess ریشه همه درخواست‌ها را به پوشه public می‌فرستد و پوشه‌های app و storage را از دسترس وب خارج می‌کند.
فایل config.php (رمز دیتابیس و کلیدها)، دیتابیس، لاگ‌ها و عکس‌های آپلودشده عمداً در مخزن نیستند.

برای آپدیت سایت: فایل‌های تغییرکرده را در public_html جایگزین کنید؛ پوشه storage و فایل config.php را دست نزنید. تغییرات دیتابیس خودکار اعمال می‌شود.
تاریخچه نسخه‌ها در CHANGELOG.md است.

## نصب (هاست cPanel / DirectAdmin)
ساختار فایل zip دقیقاً مثل پوشه اصلی هاست شماست:
```
/home/USERNAME/            ← پوشه اصلی هاست (یک سطح بالاتر از public_html)
├── app/                   ← کد برنامه (از دسترس وب خارج است)
├── storage/               ← دیتابیس SQLite، لاگ‌ها، نشست‌ها
├── config.sample.php
└── public_html/           ← فقط این پوشه از اینترنت دیده می‌شود
    ├── index.php, install.php, .htaccess
    ├── assets/
    └── uploads/
```
1. zip را در **پوشه اصلی هاست** (همان جایی که public_html قرار دارد، نه داخل آن) آپلود و Extract کنید.
   محتوای public_html داخل zip با public_html هاست ادغام می‌شود. اگر public_html فایل‌های قبلی (مثلاً index.html پیش‌فرض) دارد، اول آن‌ها را پاک کنید.
2. در cPanel یک دیتابیس MySQL با کاراکترست `utf8mb4` و یک کاربر بسازید.
3. آدرس `https://your-domain/install.php` را باز کنید، اطلاعات دیتابیس و نام کاربری/رمز مدیر را وارد کنید.
   - تیک «داده‌های نمونه» را برای دیدن سایت با خودروهای نمونه بزنید (بعداً از پنل قابل حذف‌اند).
4. پس از نصب، نصب‌کننده خودبه‌خود قفل می‌شود. پوشه‌های `storage` و `public_html/uploads` باید قابل نوشتن باشند (755).
5. ورود به پنل: `https://your-domain/admin`

> اگر نام پوشه وب هاست شما `www` یا `httpdocs` است، کافی است public_html را به همان نام تغییر دهید؛ برنامه خودکار با آن کار می‌کند.
> فقط پوشه public_html را آپلود نکنید؛ بدون app و storage سایت اجرا نمی‌شود.

## بعد از نصب (حتماً)
- در `config.php` مقدار `debug` را `false` و پس از نصب SSL مقدار `force_https` را `true` کنید.
- **پنل ← درگاه‌های پرداخت:** «درگاه آزمایشی» را غیرفعال کنید و درگاه بانک خود را با اطلاعات قرارداد فعال کنید.
  آدرس بازگشت (Callback) نمایش‌داده‌شده در همان صفحه را به بانک اعلام کنید.
- **درگاه بانک‌ها:** درگاه هر بانک از طریق یک شرکت PSP ارائه می‌شود. برای بانک سینا، سرمایه و… نوع PSP را از قرارداد ترمینال خود بررسی و در تنظیمات همان درگاه انتخاب کنید.
  PSPهای پشتیبانی‌شده: سامان‌کیش (SEP)، به‌پرداخت ملت، سداد، پارسیان (PEC)، پاسارگاد (PEP)، سپهر، آسان پرداخت، زرین‌پال، زیبال، Pay.ir، نکست‌پی.
- **پنل ← پیامک:** سامانه پیامکی (کاوه‌نگار، SMS.ir، ملی پیامک، IPPanel/فراز، قاصدک، مگفا یا هر سامانه دیگر با گزینه HTTP عمومی) را تنظیم و پیامک آزمایشی بفرستید. سپس ماژول پیامک را روشن کنید.
- **پنل ← تنظیمات عمومی:** نام، لوگو، تلفن، آدرس، لوکیشن نقشه، شبکه‌های اجتماعی و نماد اعتماد.
- **پنل ← تم و ظاهر:** رنگ‌ها، قالب آماده، فونت، گردی گوشه‌ها و حالت شب.
- **پنل ← ماژول‌ها:** هر بخش سایت (اسلایدر، فروشگاه قطعات، اقساط، مقایسه، پرداخت آنلاین و…) را روشن/خاموش کنید.

## امنیت پیاده‌سازی‌شده
- همه کوئری‌ها با Prepared Statement (ضد SQL Injection) و همه خروجی‌ها Escape شده (ضد XSS)
- توکن CSRF برای تمام فرم‌ها، Content-Security-Policy با nonce، هدرهای امنیتی و HSTS
- رمزهای عبور با `password_hash`، محدودیت تلاش ورود، نشست امن (HttpOnly، SameSite، چرخش شناسه)
- اطلاعات محرمانه درگاه‌ها و پیامک به‌صورت رمزنگاری‌شده در دیتابیس ذخیره می‌شوند
- تصاویر آپلودی اعتبارسنجی و دوباره کدگذاری (WebP) می‌شوند؛ اجرای PHP در پوشه آپلود غیرفعال است
- تأیید پرداخت اتمیک و یک‌باره (جلوگیری از تأیید تکراری) و مقایسه مبلغ با بانک
- نقش‌های کاربری: مدیر، کارشناس، اپراتور

## اجرای محلی برای تست
```
php -S 127.0.0.1:8080 -t public public/index.php
```
